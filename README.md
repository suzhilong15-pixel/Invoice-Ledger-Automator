# PDF发票识别与Excel台账生成系统

这个项目用于批量识别可复制文字的 PDF 发票，并把识别结果追加写入 Excel 台账。每次运行脚本时，新数据会追加到 `发票台账.xlsx` 的末尾，不会覆盖旧数据。

## 目录说明

```text
待识别发票/      放入需要识别的 PDF 发票
已归档发票/      识别成功后自动移动到这里
识别失败发票/    识别失败后自动移动到这里
发票台账.xlsx    自动生成和追加更新的 Excel 台账
invoice_register.py 主程序
environment.yml  Conda 环境配置
```

## 台账字段

脚本会写入以下字段：

```text
发票号码
开票日期
购买方名称
销售方名称
价税合计（小写）
美金金额
汇率
提单号
源文件名
识别状态
失败原因
处理时间
```

## 识别规则

以下字段属于必填项，只要有任意一项识别失败，PDF 就会进入 `识别失败发票/`：

```text
发票号码
开票日期
购买方名称
销售方名称
价税合计（小写）
```

`美金金额`、`汇率`、`提单号` 只在发票备注区域内按关键词判断：

- 没有在备注区域找到 `USD`，美金金额填写 `无`。
- 找到 `USD`，但无法识别后面的数字，填写 `识别失败`，并归入失败文件夹。
- 没有在备注区域找到 `汇率`，汇率填写 `无`。
- 找到 `汇率`，但无法识别后面的数字，填写 `识别失败`，并归入失败文件夹。
- 没有在备注区域找到 `提单号`，提单号填写 `无`。
- 找到 `提单号`，但无法识别后面的编号，填写 `识别失败`，并归入失败文件夹。

如果 `USD` 出现在销售方开户行、银行账号、账号、账户等信息中，脚本不会把它当作美金金额关键词。

## 重复发票处理

如果新识别的发票和台账中已有记录的发票号码相同，脚本会自动去重，只保留一条记录。保留规则是：

- 优先保留识别状态为 `成功` 的记录。
- 如果状态相同，保留发票号码、开票日期、购买方名称、销售方名称、价税合计、美金金额、汇率、提单号这些字段中识别更完整的记录。

脚本兼容关键词和数值之间存在空格、冒号、中文冒号、逗号、中文逗号等情况，例如：

```text
USD31825.00
USD 31825.00
USD:31825.00
汇率 7.2813
汇率：7.2813
提单号：YMJAM236512123
提单号986-92700554
```

## 首次使用

项目已经创建了独立 Conda 环境，位置是：

```bash
./.conda
```

如果以后需要在其他电脑重新创建环境，可以在项目根目录运行：

```bash
conda env create -p ./.conda -f environment.yml
```

## 日常使用

1. 把需要识别的 PDF 发票放入 `待识别发票/`。
2. 在项目根目录运行：

```bash
./.conda/bin/python invoice_register.py
```

3. 运行完成后查看：

```text
发票台账.xlsx
```

识别成功的 PDF 会移动到 `已归档发票/`，识别失败的 PDF 会移动到 `识别失败发票/`。

## 试运行

如果只想查看识别结果，不写入 Excel，也不移动 PDF，可以运行：

```bash
./.conda/bin/python invoice_register.py --dry-run
```

## 注意事项

- 当前脚本适用于 PDF 内文字可以复制的发票。
- 如果 PDF 是扫描件或图片版，需要另加 OCR 功能。
- 如果某类新发票进入失败文件夹，可以根据台账中的 `失败原因` 优化识别规则。
